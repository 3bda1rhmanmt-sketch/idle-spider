# Idle Spider 🕷️

A modular desktop application built with **Python** and **PySide6** designed for **Linux** environments (supporting both **X11** and **Wayland** display servers).

---

## ✨ Features

- **Cross-Compositor Support:** Native support for both X11 and Wayland display protocols.
- **Modern GUI:** Clean UI powered by PySide6 (Qt for Python) with system tray functionality.
- **Idle Detection:** Smart activity/idle monitoring and event tracking.
- **Autostart Integration:** Desktop autostart capabilities for seamless startup.
- **Modular Architecture:** Structured codebase separating UI, core logic, idle detection, and utilities.

---

## 🛠️ Tech Stack

- **Language:** Python 3.x
- **GUI Framework:** PySide6
- **Target OS:** Linux (X11 & Wayland)
- **CI/CD:** GitHub Actions

---

## 🚀 Getting Started

### Prerequisites

Ensure you have Python installed on your Linux distribution along with standard Qt dependencies.

```bash
# Ubuntu / Debian
sudo apt update
sudo apt install python3 python3-pip python3-venv

# Arch Linux
sudo pacman -S python python-pip
